# Water-charity-game

## Selected concept: Water Quest

I chose Water Quest as the project direction.

### Why this is the best fit
- It is fast, simple, and highly replayable, which makes it a strong candidate for a polished mini-game.
- The core loop is easy to understand: tap the yellow jerry cans, earn points, and chase milestones.
- It is realistic to build in a short time window without heavy assets or complex physics.
- It has clear portfolio value because it showcases UI polish, responsive interaction, game feel, scoring, and progression.

### Game concept
Players race against a timer to tap charity: water style yellow jerry cans as they appear across the play area. Each successful tap increases the score, while miss-clicks or timed obstacles create tension. The game includes:
- score counter
- combo or streak feedback
- milestone rewards
- timer and round progression
- optional obstacles such as pollution hazards or moving cans

### MVP features
- start screen and restart flow
- Easy, Normal, and Hard modes with different round lengths and spawn rates
- randomly spawning cans with click interaction
- cans and hazards are removed when clicked
- score and timer UI
- success/failure feedback text
- milestone thresholds for rewards or levels
- simple sound or animation polish
- footer links to charity: water and donation pages
- Proxima Nova-style sans-serif typography

### Stretch goals
- difficulty scaling over time
- moving obstacles that block taps
- leaderboard or local high score
- celebratory win screen and shareable result
- mobile-friendly touch controls

### Portfolio angle
This is a strong portfolio project because it blends simple mechanics with engaging visuals and a clear purpose. It feels like a complete playable game, not just a demo, and it is easy to explain and show to recruiters or collaborators.
